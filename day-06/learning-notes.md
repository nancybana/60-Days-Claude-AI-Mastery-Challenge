# Day 6 Learning Notes

## Prompt Engineering

- Prompt Engineering is the process of designing effective prompts for AI.
- Clear instructions improve AI responses.
- Context helps generate better outputs.

## ATS Learning

- ATS stands for Applicant Tracking System.
- ATS scans resumes for keywords.
- Simple resume formats are easier for ATS to read.

## NoteGPT Learning

- NoteGPT can summarize videos and documents.
- It helps create notes quickly.
- It improves learning productivity.

## Key Takeaways

1. Use relevant keywords in resumes.
2. Keep resume formatting simple.
3. AI tools can improve productivity and learning.
