# Day 07 - Choosing the Right Claude Model

## Objective

Learn the differences between Claude Haiku, Sonnet, and Opus and understand how reasoning effort affects output quality.

## Claude Models

### Haiku
- Fastest Claude model
- Best for quick questions and summaries
- Lower cost and fast responses

### Sonnet
- Balanced speed and intelligence
- Best for coding, debugging, and daily tasks
- Recommended for most users

### Opus
- Most powerful Claude model
- Best for complex reasoning, research, and advanced projects
- Higher resource usage

## Reasoning Effort Levels

### Low
- Fastest responses
- Suitable for simple tasks

### Standard
- Good balance of speed and quality
- Suitable for everyday work

### High
- Better analysis and reasoning
- Useful for coding and problem solving

### Max
- Deepest reasoning
- Best for research and difficult tasks

## My Personalized Claude Usage Strategy

- Use Haiku for summaries and quick answers.
- Use Sonnet for DSA, coding practice, and assignments.
- Use Opus for research and complex projects.
- Use Standard effort for daily work.
- Use High or Max effort when solving difficult problems.

## What I Learned

- Different Claude models are designed for different purposes.
- Choosing the correct model improves efficiency.
- Higher reasoning effort can improve output quality.
- Sonnet is the best all-round model for students and developers.
