# Day 39 – PDF Splitter & Merger

## Overview

Today, I built a **PDF Splitter & Merger** application using Claude AI. The application allows users to split PDF documents into separate pages and merge multiple PDF files into a single document through a simple web interface.

## Features

* Upload PDF files
* Split PDF into individual pages
* Merge multiple PDF files
* Preview processed documents
* Download generated PDFs
* User-friendly interface
* Browser-based processing

## Tools & Technologies

* Claude AI
* HTML
* CSS
* JavaScript
* PDF Processing Libraries

## Development Process

1. Opened Claude and started a new conversation.
2. Set the effort level to Low.
3. Provided the PDF Splitter & Merger prompt.
4. Answered Claude's interview questions.
5. Generated the complete HTML application.
6. Saved and tested the application locally.
7. Verified PDF splitting functionality.
8. Verified PDF merging functionality.
9. Downloaded and reviewed processed PDF files.
