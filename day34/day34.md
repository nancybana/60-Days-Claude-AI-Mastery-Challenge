## 🎯 Objective

Build and explore a **Marketing Detective Simulator** using Claude AI.

The goal was to investigate marketing campaign failures, analyze evidence, identify strategic mistakes, and learn practical marketing concepts through interactive case studies.

---

## 🛠️ Process Followed

- Read the provided resources
- Watched the solution video
- Opened Claude and started a new conversation
- Set effort level to **Low**
- Used the **Marketing Detective Prompt**
- Generated the complete HTML application
- Saved and launched the application in a browser
- Selected a preferred color theme
- Investigated marketing campaign cases
- Organized evidence using the investigation board
- Identified the main marketing mistake
- Reviewed expert verdicts and explanations
- Studied generated learning reports
- Replayed multiple randomized cases
- Captured screenshots of completed investigations

---

## 📚 Key Learnings

### 🔍 Marketing Analysis
- Identifying root causes behind campaign failures
- Understanding audience targeting mistakes
- Recognizing ineffective marketing strategies
- Evaluating campaign performance evidence

### 📊 Investigation Skills
- Evidence-based decision making
- Pattern recognition in marketing data
- Strategic problem-solving
- Critical analysis of campaign outcomes

### 🤖 AI-Assisted Learning
- Using AI to generate interactive simulations
- Learning through real-world inspired scenarios
- Improving analytical thinking through gamification

---

## 🚀 Features Explored

- Interactive investigation board
- Drag-and-drop evidence cards
- Marketing case analysis
- Expert verdict system
- Learning reports
- Multiple randomized scenarios
- Customizable themes

---


## 💡 Reflection

This project demonstrated how marketing concepts can be transformed into engaging investigative experiences. By analyzing evidence and diagnosing campaign mistakes, I gained a better understanding of marketing strategy, audience behavior, and decision-making processes.
