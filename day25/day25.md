# Day 25 – AI Shark Tank Simulator

## Project Overview

Today I built an AI Shark Tank Simulator using a single self-contained HTML file.

The application allows users to submit startup ideas and receive feedback from four AI judges:

* Venture Capitalist
* Founder
* Customer
* Angel Investor

The simulator evaluates startup ideas, asks questions, generates scores, and provides investment decisions.

---

## Features Implemented

### Startup Input Form

* Startup Name
* Problem Statement
* Solution
* Revenue Model
* Target Audience
* Funding Ask

### AI Judges

* VC Judge
* Founder Judge
* Customer Judge
* Angel Investor Judge

### Pitch Round

* Startup pitch display
* AI-generated questions
* User responses
* Judge reactions

### Scoring System

* Market Potential
* Innovation
* Business Model
* Execution
* Investment Worthiness

### Investment Decision

* Invest
* Reject
* Acquire
* Come Back Later

### Additional Features

* Suggested valuation
* Funding recommendation
* Leaderboard
* Share result button
* PDF report download
* Confetti celebration

---

## Testing Results

I tested the application using a sample startup idea.

The simulator successfully:

* Collected startup details
* Generated judge questions
* Calculated scores
* Produced an investment decision
* Generated valuation recommendations
* Updated the leaderboard
