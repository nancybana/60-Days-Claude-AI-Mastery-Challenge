# 🥗 NutriScope — AI Nutrition Analytics

**Day 9 | 60-Day Claude AI Mastery Challenge**

## 📌 About the Project

NutriScope is an AI-assisted nutrition analytics web application built as part of Day 9 of the 60-Day Claude AI Mastery Challenge.

The main focus of this challenge was learning the **MVP-first development approach** — build a working application first, then improve it through iterative prompting.

## 🎯 Objective

The goal was to understand how complex applications can be developed step-by-step instead of trying to build everything in a single prompt.

### Development Approach

**Stage 1 — MVP**

* Built a functional nutrition tracking application
* Added food and nutrition entries
* Calculated calories and macronutrients
* Created a daily nutrition dashboard

**Stage 2 — Enhancement**

* Improved the existing MVP using a second prompt
* Added advanced functionality while keeping the original features working

## 🚀 MVP Features

* Add food entries
* Track calories
* Track protein, carbohydrates and fats
* Automatic nutrition calculations
* Daily macro balance
* Food log
* Remove food entries
* Input validation
* Responsive design
* Single-file HTML application

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Claude AI Artifacts

## 🧠 Key Learning

The biggest learning from Day 9 was the importance of **iterative prompting**.

Instead of asking Claude to build a complete application in one large prompt, I learned to follow a structured process:

**Build → Test → Improve → Test Again**

Starting with a working MVP makes it easier to understand the application, identify improvements, and enhance it step-by-step.
