Hi Nancy! Great that you're planning this early — 2nd year is honestly the best time to lock in a solid roadmap. Since you already have basic C++/DSA and are picking up web dev, let's build a semester-wise plan aimed at internships + a good SWE job by graduation.

## Overall Strategy (2nd year → Graduation)

**3 pillars chalti rahengi parallel:** DSA (daily), one strong tech stack (web dev), and projects + open source + resume building.

---

### 3rd Semester (Abhi - if just started 2nd year)
- **DSA**: Arrays, Strings, Recursion, Basic Sorting/Searching, Time Complexity — solve on LeetCode/GFG (aim 3-4 problems/day, start with Striver's A2Z sheet)
- **Web Dev**: HTML, CSS (Flexbox/Grid), JS fundamentals (DOM, ES6+)
- **Extra**: Git/GitHub properly (branches, PRs) — you already know basics from your CodeAlpha internship
- **Goal**: Build 1-2 small static projects (portfolio site)

### 4th Semester
- **DSA**: Linked List, Stack, Queue, Hashing, Two Pointers, Sliding Window (aap already linked list + hashing kar chuki ho, ab practice depth badhao)
- **Web Dev**: Learn React.js (aapne nature gallery project kiya hai — ab state management, hooks deeply, React Router seekho)
- **Backend intro**: Node.js + Express basics, MongoDB or SQL basics
- **Goal**: Build 1 full MERN mini-project (e.g., a to-do app with auth, or expand your Flipkart clone into a real backend-connected app)
- **Start applying**: Off-campus/remote micro-internships, open source (Hacktoberfest jaisa), continue CodeAlpha-type internships for resume

### 5th Semester (Placement prep season shuru)
- **DSA**: Trees, BST, Heaps, Graphs (BFS/DFS), Greedy — this is core interview territory
- **CS Fundamentals**: OOPs (strong — you've done this in Banking System project), DBMS, OS basics, Computer Networks basics — these get asked in interviews
- **Web Dev**: Deploy full-stack projects (Vercel/Render), learn REST API design properly, maybe TypeScript
- **Goal**: 2 solid full-stack projects on GitHub with good READMEs, start LinkedIn presence (post project updates)
- **Internship hunt starts seriously**: Apply to summer internships (on-campus if ABES has drives, + Internshala, LinkedIn, Unstop)

### 6th Semester (Summer internship + more DSA)
- **DSA**: Dynamic Programming, Backtracking, Tries, advanced Graphs — this is where most people struggle, give it time
- **Do a Summer Internship** (after 6th sem) — SWE/dev role, even unpaid/small startup is fine for experience
- **System Design basics**: Low-level design (OOP-based), start reading about scalability basics
- **Goal**: Internship experience + 1 project that solves a real problem (good for resume storytelling)

### 7th Semester (Placement season)
- **DSA**: Revision + timed contests (Codeforces/LeetCode contests weekly)
- **Resume finalized**: Projects, internship, DSA count (300+ problems solved target)
- **Apply aggressively**: On-campus placements, off-campus (referrals via LinkedIn), mock interviews
- **Mock interviews + HR prep**

### 8th Semester
- Continue interviews, finish pending offers process, maybe a capstone project
- Keep contributing to open source / personal brand on LinkedIn/GitHub
